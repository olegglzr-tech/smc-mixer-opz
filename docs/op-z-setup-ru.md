# SMC-Mixer + OP-Z: громкость треков фейдерами

## Важно: прошивка не менялась

Это **не кастомная прошивка**. Меняется только профиль `CC / User` (6 282 байта)
в пользовательской области flash. Заводская прошивка, `app.bin` и его MD5
остаются заводскими.

- Устройство остаётся на заводской прошивке (V012 или V013).
- Обновлять прошивку не нужно.
- Настройку можно откатить, записав свой бэкап.
- Режим `DAW` / `User` не входит в профиль: он переключается кнопками на
  самом микшере.

Проверено на V012. На V013 протокол настроек, скорее всего, такой же, но
отдельно не проверялся.

## Что получится

| Контрол | Сообщение |
|---|---|
| Фейдеры 1–8 | `CC16`, каналы 1–8, значения 0–127 |
| Mute 1–8 | `CC53`, каналы 1–8, переключатель 0/127 |
| Solo 1–8 | `CC20–27`, канал 1, переключатель 0/127 |
| Энкодеры 1–8 | остаются заводскими: `CC30–37`, канал 1 |

Фейдеры управляют громкостью треков OP-Z. Mute работает как обычный
переключатель mute.

**Solo не делает настоящий solo.** В OP-Z нет отдельного solo-CC. Кнопки Solo
пока только отправляют `CC20–27`; чтобы они реально солоили, нужен внешний
MIDI-роутер или кастомная прошивка.

Энкодеры в этой настройке остаются заводскими и на OP-Z ничего не меняют.
Опционально их можно перевести на filter cutoff — см. раздел «Энкодеры».

## Что нужно

- SMC-Mixer;
- USB-C кабель с передачей данных;
- компьютер для настройки;
- OP-Z;
- для Linux-утилиты: `alsa-utils` (`amidi`).

```sh
# Arch / Omarchy
sudo pacman -S alsa-utils

# Debian / Ubuntu
sudo apt install alsa-utils
```

На Windows/macOS можно использовать SMC-Mixer Tool или MidiSuite и выставить
поля вручную по таблице в конце.

## 1. Сделайте бэкап

Подключите SMC-Mixer к компьютеру, **не к OP-Z**.

```sh
cd ~/Projects/smc-mixer-fw

./tools/smc_mixer.py ports
./tools/smc_mixer.py info
./tools/smc_mixer.py dump dumps/settings-mine.bin
```

`settings-mine.bin` — ваш личный бэкап. Не перезаписывайте его. Именно этим
файлом потом можно вернуть всё как было.

## 2. Запишите профиль

```sh
./tools/smc_mixer.py apply-opz --out dumps/settings-opz.bin
./tools/smc_mixer.py show dumps/settings-opz.bin --profile cc
```

Без `--knob-cc` команда меняет фейдеры, Mute и Solo, а энкодеры оставляет как
есть. В выводе `show` должно быть (если энкодеры не менялись):

- Faders 1–8: `cc=16`, channel 1–8;
- Mute 1–8: `cc=53`, channel 1–8, mode 1;
- Solo 1–8: `cc=20–27`, channel 1, mode 1;
- Knobs 1–8: заводские `cc=30–37`, channel 1.

Настройки сохраняются в flash микшера и переживают отключение питания.

Если не хотите запускать `apply-opz`, можно записать готовый профиль:

```sh
./tools/smc_mixer.py write profiles/opz-volume-faders.bin
```

Он меняет только профиль `CC / User`, DAW-профиль не трогает. В нём
энкодеры заводские (`CC30–37`), поэтому он перезапишет текущие настройки
энкодеров в CC-профиле.

## 3. Переключите live-режим микшера

Это отдельная операция, она не входит в профиль.

- **User / CC:** зажмите `Shift` и нажмите крайнюю правую кнопку `Right`.
- **DAW:** зажмите `Shift` и нажмите крайнюю левую кнопку `Left`.

`Channel Left/Right` — это Bank Previous/Next, они **не** переключают режим.

После каждого переподключения или включения проверяйте режим: микшер может
оказаться в DAW. В DAW фейдеры отправляют Pitch Bend (`E0`), а не `CC16`.

Проверка на компьютере:

```sh
amidi -l
amidi -p hw:1,0,1 -d
```

Двигайте фейдер 1. В User/CC-режиме должно быть примерно так:

```text
B0 10 01
B0 10 02
B0 10 03
```

`B0` — канал 1, `10` — CC16, последний байт — значение. Для фейдера 2 будет
`B1 10 xx`, для фейдера 8 — `B7 10 xx`.

Если вместо этого идёт `E0 00 00 xx`, микшер в DAW-режиме. Переключите его
снова: `Shift + Right`.

Номер порта `hw:1,0,1` может отличаться. Смотрите его в `amidi -l`; для
захвата нужен порт `Master`, для настройки утилита сама использует `Private`.

## 4. Настройте OP-Z

1. Подключите SMC-Mixer к OP-Z по USB-C. OP-Z — USB-хост.
2. Включите приём внешнего MIDI: зажмите `Tempo + Screen` и, **не отпуская**,
   нажмите `2`. Это переключатель `incoming MIDI`; если он уже включён,
   повторно нажимать не нужно.
3. Проверьте `channel_one_to_active`. Если опция включена, канал 1 управляет
   активным треком, а не треком 1. Для управления «фейдер 1 → трек 1»
   выключите её или используйте фейдеры 2–8.
4. Проверьте, что MIDI-каналы треков OP-Z совпадают с каналами фейдеров.
5. Подвигайте фейдеры 1–8. Должна меняться громкость соответствующих треков.

## Если не работает

- **Фейдеры шлют `E0`, а не `B0 10`** — микшер в DAW-режиме. `Shift + Right`.
- **Фейдеры шлют `CC16`, но OP-Z молчит** — проверьте `incoming MIDI`,
  `channel_one_to_active` и MIDI-каналы треков.
- **Фейдер 1 управляет не тем треком** — скорее всего, включён
  `channel_one_to_active`; выключите его или используйте другой фейдер.
- **OP-Z не видит микшер / не хватает питания** — попробуйте USB-C хаб с
  внешним питанием. OP-Z рассчитан примерно на 100 мА на USB-порт.
- **OP-Z не поддерживает устройство с несколькими MIDI-портами** — SMC-Mixer
  показывает два порта (`Private` и `Master`). Если OP-Z не видит микшер,
  это может быть ограничением OP-Z; тогда нужен USB-хост/роутер.
- **Solo не солоит** — так и задумано. В OP-Z нет solo-CC; нужен роутер или
  кастомная прошивка.

## Энкодеры (опционально)

Сейчас энкодеры оставлены заводскими: `CC30–37`, канал 1. На OP-Z они ничего
не делают.

Если нужен filter cutoff:

```sh
./tools/smc_mixer.py apply-opz --knob-cc 3
```

Тогда энкодеры 1–8 будут отправлять `CC3` на каналах 1–8. Для Parameter 1
используйте `--knob-cc 1`, для Parameter 2 — `--knob-cc 2`.

Не используйте `CC32–49` без переключения энкодеров в относительный режим
(type 3): заводской тип отправляет абсолютные значения.

Вернуть энкодеры как было можно своим бэкапом:

```sh
./tools/smc_mixer.py write dumps/settings-mine.bin
```

## Ручная настройка (Windows/macOS)

Если не используется Linux-утилита, выставьте в SMC-Mixer Tool / MidiSuite:

| Контрол | Тип | Канал | CC | Значения |
|---|---|---|---|---|
| Fader 1–8 | CC | 1–8 | 16 | min 0, max 127 |
| Mute 1–8 | CC Toggle | 1–8 | 53 | off 0, on 127 |
| Solo 1–8 | CC Toggle | 1 | 20–27 | off 0, on 127 |
| Knob 1–8 | CC Abs | 1 | 30–37 | min 0, max 127 |

После записи не забудьте переключить live-режим в **User / CC**:
`Shift + Right`.

## Откат

```sh
./tools/smc_mixer.py write dumps/settings-mine.bin
```

Это вернёт профиль, который был до настройки. Прошивка при этом не меняется.
